# Linmas 0.9.0

Released on October 1, 2026 (UTC). Available on [npm](https://www.npmjs.com/package/linmas/v/0.9.0) and [GitHub Releases](https://github.com/TanKimGwan/linmas/releases/tag/v0.9.0).

Clarifies operation-level compatibility evidence for all eleven canonical skills and seven MCP tools. Distinguishes Claude Code installation from Claude API execution and Hermes format compatibility from runtime verification. Adds a bound-reference MCP validation runbook and retains the 0.8.0 Windows destructive-operation denial.

The release also includes portable test fixtures and hardened release automation: Linux sandbox checks, Windows Git discovery, artifact integrity checks, and publication provenance. Existing CLI and skill identities remain compatible with 0.8.0; publication does not establish live provider or production runtime behavior.

## Upgrade from 0.8.0

No user data migration is required. Node.js 24 or newer remains required.

For the npm CLI:

```bash
npm install --global linmas@0.9.0
linmas --version
```

For a new Codex marketplace installation, use `--ref v0.9.0`. If the marketplace is already pinned to an older tag, remove the installed plugin and old marketplace registration before registering the new ref; `marketplace upgrade` only refreshes the configured ref. Verify the installed version, restart Codex, and open a fresh task.

The 0.8.0 Windows destructive-operation denial remains in place. Human review, transmission consent, and write consent remain separate requirements.

See the [implementation notes](../docs/implementation/v0.9.0.md) and [compatibility evidence policy](../docs/compatibility/COMPATIBILITY.md) for the scope and limits of the evidence. Historical candidate records describe their own revisions; release artifacts and provenance identify the bytes actually published.
