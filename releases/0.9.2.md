# Linmas 0.9.2

Linmas 0.9.2 adds a native managed installer for Claude Code and Codex skills.

- Install selected skills in a project or user-home scope using copy or symlink attachments.
- Preview changes, record ownership in a scoped manifest, inspect managed state with `doctor`, and remove selected skills with scoped `uninstall`.
- Preserve unmanaged or locally modified content unless the user confirms a backup and replacement.
- Offer a copy fallback only for unsupported symlink operations after a clean rollback; retain and report recovery data when rollback is incomplete.
- Fail closed for managed install and uninstall apply on Windows where safe handle-relative filesystem mutation is unavailable.
- Document the npm CLI, source-checkout workflow, and Agent Skills CLI as separate installation paths.

Install or upgrade with Node.js 24 or newer:

```bash
npm install --global linmas@0.9.2
linmas list
```

The older unscoped install and uninstall commands remain available. This release does not add a Windows managed-apply implementation or establish live provider, MCP, or production runtime behavior.
