# Linmas 0.9.1

Documentation and branding follow-up to Linmas 0.9.0.

- Updates the npm and GitHub README to describe the published 0.9.0 capabilities and upgrade path.
- Replaces the README logo with the current Linmas website logo.
- Corrects the package and release version badges.
- Adds no runtime, security-policy, CLI, skill, MCP, or data-format changes.

Existing 0.9.0 installations do not require an upgrade for functionality. Install 0.9.1 when you want the refreshed package documentation and metadata:

```bash
npm install --global linmas@0.9.1
linmas --version
```

No data migration is required. The compatibility boundaries and upgrade guidance remain documented in the [0.9.0 release notes](0.9.0.md).
